1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
Project Name: Strokes of Anna
Project Type: Professional Art Showcase & Portfolio
Core Objective: To showcase Anna's artwork in an editorial-grade, premium digital environment.

2. DESIGN SYSTEM & AESTHETICS
--------------------------------------------------------------------------------
Primary Aesthetic: Minimalist, Editorial, Premium, Human & Organic
Palette:
- Background: Warm Parchment (hsl(35, 30%, 95%) / #F5F2ED approx.)
- Foreground: Deep Charcoal Ink (hsl(0, 0%, 15%) / #262626)
- Accent: Terracotta Wash (hsl(12, 40%, 50%) / #D14D33 approx.)
- Muted: Warm Dove Grey (hsl(35, 15%, 92%))
- Border/Lines: Soft Ochre Edge (hsl(35, 20%, 85%))

Typography:
- Script/Heading: 'Dancing Script' (Google Fonts)
- Serif/Body: 'EB Garamond' (Google Fonts)
- Note Style: Italicized EB Garamond

Key Visual Features:
- Custom Brush-Tip Cursor (interactive)
- Smooth Scroll (Lenis Implementation)
- Parallax & Staggered Reveal Animations (Framer Motion)
- Minimalist navigation with floating header
- Paper-like textures and organic clip-paths for images

3. SITE ARCHITECTURE (PAGES & ROUTES)
--------------------------------------------------------------------------------
- Home (/) : Hero section, featured story, and newsletter.
- About (/about) : Detailed biography and artist statement.
- Gallery (/gallery) : Full paginated collection of all artworks.
- Contact (/contact) : Inquiry form for collectors.
- Impact (/impact) : Philanthropic and narrative impact of the work.
- Artwork Detail (/artwork/:id) : Focused view of individual pieces with magnifying details.
- 404 (/not-found) : Custom error page maintaining site aesthetic.

5. TECHNICAL STACK
--------------------------------------------------------------------------------
- Framework: React (Vite-powered)
- Language: TypeScript
- Styling: Tailwind CSS
- Animation: Framer Motion
- Scrolling: Studio Freight (Lenis) Smooth Scroll
- Components: Shadcn UI (Radix-based)
- Data Fetching: React Query (TanStack Query)
- Deployment: Compatible with Vercel/Netlify/Vite-ready hosts

6. ASSET MANAGEMENT
--------------------------------------------------------------------------------
- Main Art Assets: Located in /src/assets/
- Organization: Divided into base folder and /assets/1/ for collection phases.
- Formats: High-resolution PNG and JPEG.
- Responsive Handling: Images utilize custom clip-paths and object-contain for an organic feel.
